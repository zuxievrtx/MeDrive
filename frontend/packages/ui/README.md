# medrive_ui

Design system MeDrive: token warna/spasi/radius, tema Material (font Nunito), format tanggal
Indonesia, dan widget bersama (tombol, field, badge status, kartu, state loading/kosong/error,
dialog, peta OSM `MedMapView` dengan cache tile). Tidak bergantung pada `medrive_core`, sehingga
bisa dipakai aplikasi driver.
